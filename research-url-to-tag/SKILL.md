# 调研链接并生成标签笔记

逐一访问用户提供的链接，优先参考项目官网、官方仓库或原始资料，核实名称、主要功能和用途；需要时查阅其他可靠来源。无法访问或核实的内容明确标注，不根据名称或猜测编造。

默认用中文为每项生成相关的 `#标签` 和不超过 100 字的简要说明。标签选择能帮助分类和检索的关键词；说明聚焦项目做什么、能用于什么。保留用户给出的链接，按原顺序输出，链接本身作为来源。若用户指定语言、字数或格式，以用户要求为准。

每个项目使用独立的顶层标签节点，将项目名称、链接和说明放在其下方的一个缩进子节点，方便直接复制到 Markdown 或大纲笔记：

```markdown
- #视频修复 #目标移除 #计算机视觉
  - [项目名称](https://example.com/)：一句简洁、经过核实的项目说明。
```

默认直接输出整理后的列表，不添加无关前言或总结；如来源不可用，简短说明核实限制。
